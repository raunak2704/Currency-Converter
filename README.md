# Currency Converter – PS No. 40

## Project Overview
A Python-based console application that converts currencies between INR, USD, EUR, and GBP.

## Supported Currencies
- INR – Indian Rupee
- USD – US Dollar
- EUR – Euro
- GBP – British Pound

## Exchange Rates
- 1 INR = 1 INR
- 1 USD = 83 INR
- 1 EUR = 90 INR
- 1 GBP = 105 INR

## Technologies Used
- Python 3
- Dictionary
- Functions
- Conditional Statements
- Exception Handling

## How to Run

```bash
python3 currency_converter.py
```

## Features
- Currency conversion through INR
- Input validation
- Negative amount validation
- Two-decimal precision
